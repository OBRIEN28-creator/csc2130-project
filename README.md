#### Project Description

This project is a web-based academic management platform designed to help university students organize,plan and track their studies in one place.

Instead of using separate notebooks,calendars,apps,and files, a student can use the platform to:
1.Manage their class timetable
2.Track assignments,projects and deadlines
3.Find and organize study resources
4.Create Course notes
5.Track exams and revision
6.Record grades and monitor academic progress
7.View everything from a personalized student dashboard.
